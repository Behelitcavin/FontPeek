# FontPeek · 글꼴 미리보기

PC에 설치된 글꼴로 같은 문장을 한꺼번에 비교하는 Windows용 위젯입니다. 클립 스튜디오 옆에 띄워 두고 일본어 글꼴을 고를 때 사용할 수 있습니다.

## 다운로드 및 실행

1. [FontPeek v1.0.0 ZIP 다운로드](dist/FontPeek_v1.0.0.zip?raw=true)
2. ZIP 파일의 압축을 풉니다.
3. `FontPeek.exe`를 실행합니다.

Windows 10/11 64비트용이며, 별도 설치 없이 실행합니다. 글꼴은 사용자의 PC에 설치된 것을 사용합니다.

## 사용 방법

- 위쪽 입력란에 미리 볼 문장을 입력합니다. Enter로 줄을 나눌 수 있습니다.
- **글꼴 검색**: 이름 일부로 검색합니다. 영문 대소문자를 구분하지 않으며 Esc로 검색어를 지웁니다.
- **고정**: 다른 창 위에 항상 표시합니다.
- **가로 / 세로**: 가로쓰기와 세로쓰기를 전환합니다.
- **일본어만**: 해제하면 PC의 모든 글꼴을 표시합니다.
- **슬라이더**: 글자 크기를 조절합니다.
- **글꼴 카드 클릭**: 글꼴 이름을 클립보드에 복사합니다. 클립 스튜디오의 글꼴 목록에서 붙여넣어 찾을 수 있습니다.
- **글꼴 이름에 마우스 올리기**: 잘린 이름 전체를 확인합니다.

창 위쪽을 끌어 이동하고 가장자리를 끌어 크기를 조절합니다. 창 위치·크기·문장·표시 설정은 종료할 때 저장됩니다.

설정 파일은 `%LOCALAPPDATA%\FontPeek\settings.txt`입니다. 이 파일을 지우면 초기 상태로 돌아갑니다.

## 표시 방식

- 글꼴에 없는 문자는 `□`로 표시합니다.
- 비교하기 쉽도록 모든 글꼴에 같은 줄바꿈 위치를 적용합니다. 폭이 넓은 글꼴은 끝부분이 잘릴 수 있습니다.
- 세로쓰기는 Windows의 세로쓰기 기능을 사용하며, 지원이 부족한 글꼴은 문자 회전과 위치 보정으로 표시합니다. 클립 스튜디오의 세로쓰기와 차이가 있을 수 있습니다.
- 새 글꼴을 설치한 뒤에는 FontPeek를 다시 실행합니다.

## 소스에서 빌드

Windows에 포함된 .NET Framework 4.x C# 컴파일러를 사용합니다. 외부 라이브러리는 필요하지 않습니다.

저장소 폴더에서 PowerShell로 실행합니다.

```powershell
.\build.ps1
```

빌드 결과는 같은 폴더의 `FontPeek.exe`입니다. 배포 ZIP에서는 `source` 폴더 안에서 빌드합니다.
